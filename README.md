# Worst Calculator Ever

Open `index.html`.

- Only supports addition: `a + b`
- `a` and `b` are limited to `[-100, 100]`
- If the sum goes outside `[-100, 100]`, it shows `err idk` and offers a `show me` button
- Pressing `show me` forces `67` and shakes the calculator
- After that, another out-of-range attempt intentionally crashes with the requested message
